Project Description

Medicine Intake Reminder is a simple system designed to remind users to take their medicines at the scheduled time.

The project helps reduce the chances of forgetting medicines by providing a timely reminder.

The Problem

People often forget to take their medicines on time, especially when they are busy or have multiple medicines to take.

The Solution

Our project provides a reminder at the scheduled medicine time. The user can set the medicine time, and the system alerts them when it is time to take the medicine.
